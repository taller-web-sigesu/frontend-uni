# Frontend — Universidad Actúa

Aplicación inicial en React + Vite, basada en [`DESIGN.md`](DESIGN.md). Por
ahora muestra una pantalla de estado del frontend y la conexión con el backend;
no implementa funcionalidades del sistema.

- Dirección local: [http://localhost:3000](http://localhost:3000)
- Desarrollo: Vite HMR detecta cambios en `src/`.
- API: las solicitudes `/api` se reenvían al servicio `backend`.
- Docker: se ejecuta desde `infra-uni/iniciar.bat`; no requiere Node.js local.

## Trabajo en equipo

**Obligatorio:** crea una rama por tarea (`feature/...`, `fix/...` o `docs/...`)
desde `main`. No cambies ni confirmes trabajo directamente en `main`; integra
mediante una PR revisada por otro compañero.
